# Project Workbench test Vault runbook

1. Open `test-vault` in Obsidian.
2. Enable the same `research-workbench` bundle for the active desktop or mobile configuration.
3. Run **Open project workbench** from the command palette.
4. Switch between projects and the five navigation panels.
5. Create a project, problem, task, and explicitly pending input.
6. Edit problem status/stage/role, set focus, associate an existing problem, and archive an item.
7. Open the filter panel and verify status, stage, role, full-text, and archived filters.
8. Open the problem body and project note in Obsidian's native editor.
9. Repeat the core flow on a narrow/mobile layout.
10. Run `npm test`, `npm run typecheck`, `npm run build`, and `node scripts/check-device-configs.mjs --vault test-vault`.

The fixture is generic and contains no personal Vault data. Formal Vault installation is a separate, explicitly gated handoff.
